# ❤️ Love Proposal Page

A beautiful and interactive **Love Proposal Web Page** built with **HTML, CSS, and JavaScript**.

This project creates a romantic proposal experience with animated backgrounds, beautiful messages, typing effects, love animations, and an interactive accept button.

> This project is created for learning and creative frontend practice.

---

## ✨ Features

- 💖 Beautiful gradient background
- 💌 Romantic proposal messages
- ⌨️ Automatic typing text animation
- 🌹 Love animation effects
- 🖼️ Custom image support
- 🎉 Interactive accept button
- 📱 Responsive design
- ⚡ Smooth frontend animations

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

---

## 🚀 Installation & Usage

Clone the repository:

```bash
git clone https://github.com/iamdeveloperrayhan/love-proposal-page.git
```

Go to the project folder:

```bash
cd love-proposal-page
```

Now open:

```text
index.html
```

in your browser.

No extra installation or dependencies are required.
